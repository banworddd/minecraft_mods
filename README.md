# Minecraft Mods Collection

Коллекция модов для Minecraft 1.20.1 на Fabric.

## Клиентские моды

### Xaero's Minimap
**Версия:** 25.2.6-Fabric-1.20  
Мини-карта и полноэкранная карта для навигации.

### Ambient Sounds
**Версия:** 6.3.1-FABRIC-1.20.1  
Атмосферные звуки окружающей среды в зависимости от биома.

### AppleSkin
**Версия:** 2.5.1-fabric-mc1.20.1  
Показывает точное значение голода и насыщения в интерфейсе.

### Falling Leaves
**Версия:** 2.1.2-1.20.1  
Анимация падающих листьев под деревьями.

### Sodium
**Версия:** 0.5.13-fabric-1.20.1  
Оптимизация рендеринга, значительно повышает FPS.

### Iris
**Версия:** 1.7.6-mc1.20.1  
Поддержка шейдеров на Fabric, работает вместе с Sodium.

### Indium
**Версия:** 1.0.36-mc1.20.1  
Поддержка RenderLayer API для Sodium, необходим для некоторых модов.
